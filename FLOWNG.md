# FlowNG

FlowNG — форк [v2rayNG](https://github.com/2dust/v2rayNG) с интерфейсом на Jetpack Compose и Material 3. VPNService, Xray-core, протоколы, импорт профилей, подписки и маршрутизация остаются компонентами исходного проекта. Исходный код распространяется на условиях [GPL-3.0](LICENSE); авторство исходного проекта сохраняется.

## Скачать APK без Android Studio

1. Откройте [Actions → FlowNG debug APK](https://github.com/chistik21/FlowNG/actions/workflows/flowng-debug.yml).
2. Нажмите **Run workflow**, выберите ветку `flowng/development` и подтвердите запуск.
3. После успешного завершения скачайте артефакт **FlowNG-debug-apks** со страницы запуска и распакуйте ZIP на телефоне.
4. Установите debug APK для архитектуры устройства (обычно `arm64-v8a`; `universal` подходит для любой поддерживаемой архитектуры). Разрешите установку из выбранного источника в системном диалоге Android.

Workflow загружает вложенные submodules, собирает HEV через Android NDK, скачивает `libv2ray.aar` для закреплённого коммита AndroidLibXrayLite, выполняет unit-тесты и `:app:assemblePlaystoreDebug`. Секреты и ключи для debug-сборки не нужны. При ошибке откройте шаг, отмеченный красным: подробности Gradle доступны благодаря `--stacktrace`.

При ручном запуске workflow дополнительно устанавливает x86_64 APK в Android-эмулятор и проверяет, что главный экран открывается без немедленного завершения процесса. Эта проверка не подтверждает установку VPN-соединения с конкретным сервером.

Статистика на главном экране берётся из Xray в процессе VPN/прокси-сервиса. До первого измерения или при выключенной опции «Отображать скорость» вместо чисел показывается «—». Время и объём отсчитываются с начала сбора статистики текущего соединения; данные не подменяются искусственными значениями.

**Важно:** успешная сборка APK не доказывает работоспособность соединения на каждом устройстве. Проверьте подключение, разрешение VPN, импорт и обновление подписок на телефоне перед постоянным использованием. Debug APK подписан стандартным отладочным ключом GitHub runner; он не предназначен для публикации в магазинах.

Идентификатор приложения пока оставлен исходным (`com.v2ray.ang`), чтобы не нарушить внутренние ссылки на сервисы и распознавание Xray. Поэтому FlowNG и установленный v2rayNG одновременно установить нельзя; при несовпадении подписей обновление поверх существующего клиента не выполнится. Перед удалением старой версии экспортируйте профили и настройки в её разделе резервного копирования.
